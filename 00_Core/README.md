# 00_Core

RDL Music Theoryの入口、Music Core、Music v0.2再構成入口を置く領域。

現段階では既存ルート文書を物理移動しない。ここは新構造の責務境界を示す入口であり、旧パスとの対応は文書地図で管理する。

現行T0/T1基準での責務:

```text
Music固有の目的を保持する
対象側SILN_music / W_music、有限作用断面RIB_B、自己側M_Bを分離する
BはPurpose・対象範囲・選択関係・interaction/action section・比較条件を有限に固定する
F = interp(M_B, RIB_B) として作用解釈を扱う
FとF'は同じ更新前M_Bで形成する
E / reviewed unresolved H / θ / M_Δ / ξ の層を混同しない
W_music / Γ / C_rel / I(M_B) はMusic-localな補助記述・検証規則でありT0 primitiveへ昇格させない
T2抽出後にMusicへ戻る停止線を保持する
```

ここに置く文書は、T2抽出を増やすためではなく、Music本線を音楽対象・分析・生成・再聴取へ戻すための入口として扱う。
